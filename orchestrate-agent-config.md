# Orchestrate Agent Configuration — Security Approver Agent

## Overview

This document specifies the complete configuration for the **Security Approver Agent** deployed
in IBM watsonx Orchestrate. This agent is the human-in-the-loop gate in the Actor-Critic security
review pipeline. It consumes SARIF v2.1.0 reports produced by the `watsonx_security_audit` MCP tool
and makes PR approval/rejection decisions based on finding severity.

---

## Step 1 — Expose the MCP Server (ngrok Tunnel)

The `watsonx_mcp_server.py` server runs locally over stdio for Bob IDE. To connect it to
watsonx Orchestrate (which requires an HTTP/HTTPS endpoint), you must expose it via a tunnel.

### Start the HTTP MCP server

**Windows:**
```batch
start_server.bat
```

**Linux / macOS:**
```bash
chmod +x start_server.sh
./start_server.sh
```

This starts the server at `http://127.0.0.1:8000`.

### Create the ngrok tunnel

1. Download ngrok: https://ngrok.com/download
2. Sign up for a free account at https://dashboard.ngrok.com
3. Authenticate: `ngrok config add-authtoken <your-ngrok-authtoken>`
   - Get your authtoken from: https://dashboard.ngrok.com/get-started/your-authtoken
4. Start the tunnel in a new terminal window:
   ```bash
   ngrok http 8000
   ```
5. Copy the public HTTPS URL shown, e.g.:
   ```
   Forwarding   https://abc123.ngrok-free.app -> http://localhost:8000
   ```

The URL `https://abc123.ngrok-free.app` is your **MCP server endpoint URL** for Orchestrate.

> **Note for hackathon submission:** If live ngrok tunneling is restricted in your environment,
> this document and the architecture diagram in `ARCHITECTURE.md §6` constitute the equivalent
> design evidence. The server code (`watsonx_mcp_server.py`) is fully functional in HTTP mode.

## Step 2 — Register the MCP Tool in watsonx Orchestrate

1. Log in to IBM Cloud: https://cloud.ibm.com
2. From the Resource List, find your **watsonx-Hackathon Orchestrate** instance and launch it.
3. Navigate to **Discover** (the left-side catalog icon).
4. Click **Tools** tab → **Add a tool** button.
5. Select **MCP server** as the tool type.
6. Fill in the connection form:

| Field | Value |
|-------|-------|
| **Tool name** | `watsonx_security_audit` |
| **MCP server URL** | `https://<your-ngrok-subdomain>.ngrok-free.app` |
| **Transport** | Streamable HTTP (SSE) |
| **Description** | Sends code diffs to watsonx.ai for OWASP security analysis. Returns a Markdown report and SARIF v2.1.0 JSON. |

7. Click **Connect** — Orchestrate will discover the `watsonx_security_audit` tool automatically
   from the MCP server's tool manifest.
8. Confirm the tool appears in your tool library.

## Step 3 — Create the Security Approver Agent

1. In watsonx Orchestrate, click **Create an agent** (top-right button).
2. Select **Create from scratch**.
3. Fill in the agent configuration:

### Agent Name
```
Security Approver Agent
```

### Instruction Prompt (paste verbatim)
```
You are a Tech Lead. Your job is to review the SARIF v2.1.0 JSON reports generated by the
watsonx.ai Critic. If there are HIGH severity issues, reject the PR and notify the developer.
If the issues are mitigated, approve the PR.

Workflow:
1. When given a code diff or file path, call the watsonx_security_audit tool with the diff.
2. Parse the returned SARIF v2.1.0 JSON block.
3. Count findings by severity: CRITICAL, HIGH, MEDIUM, LOW, INFO.
4. Decision logic:
   - If CRITICAL count > 0: REJECT — respond "PR REJECTED: Critical vulnerabilities found. 
     Developer must address [list findings] before re-submission."
   - If HIGH count > 0: REJECT — respond "PR REJECTED: High severity issues detected. 
     Developer must remediate [list findings] before merge."
   - If MEDIUM count > 0 and no CRITICAL/HIGH: CONDITIONAL APPROVAL — respond 
     "PR CONDITIONALLY APPROVED: Medium-severity findings noted. Create follow-up tickets 
     for [list findings] within 2 sprints."
   - If only LOW/INFO findings: APPROVE — respond "PR APPROVED: No critical or high severity 
     security issues detected. Low/informational findings: [list]."
5. Always include the full finding list with CWE IDs and line numbers in your response.
6. Sign off with: "Reviewed by: Security Approver Agent | watsonx Orchestrate | IBM Granite"
```

### Tool Assignment
- Add the registered **`watsonx_security_audit`** tool to this agent.
- Leave all other tool settings at default.

### Agent Settings
| Setting | Value |
|---------|-------|
| **Model** | IBM Granite (default for Orchestrate) |
| **Memory** | Session memory enabled |
| **Language** | English |

4. Click **Save** to publish the agent.

## Step 4 — Test the Agent (Sample Invocation)

Once the agent is live, test it with a sample prompt:

```
Review this code for security issues and tell me whether to approve or reject the PR:

+ import sqlite3
+ def get_user(uid):
+     conn = sqlite3.connect('db.sqlite')
+     cursor = conn.cursor()
+     query = "SELECT * FROM users WHERE id = " + uid
+     cursor.execute(query)
+     return cursor.fetchall()
```

**Expected response:**
- Tool `watsonx_security_audit` is invoked with the diff
- SARIF JSON is returned and parsed
- Agent identifies SQL Injection (CRITICAL/HIGH, CWE-89, OWASP A03)
- Agent responds: **PR REJECTED** with finding details and remediation guidance

    +----------------------------->|
                                   |  MCP stdio

                                   |
                                   |  IBM IAM token exchange
                                   |  POST /ml/v1/text/generation

                            watsonx.ai

                                   |
                             SARIF v2.1.0 report

                                   v
                          Bob IDE displays report
                                   |
                                   | (manual trigger or CI webhook)
                                   v
                         +---------+-----------+
                         |   ngrok HTTPS tunnel |
                         +---------+-----------+
                                   |
                                   | HTTP/SSE MCP
                                   v
                     watsonx_mcp_server.py

                    watsonx Orchestrate

                         IBM Granite model
                                   |
                     PR Approve / Reject decision
